2.2 缩放点积注意力 (Scaled Dot-Product Attention)

本节核心认知目标：
彻底掌握深度学习史上最具影响力的核心公式 $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$，完成 2 个 Token、2 维特征的全流程极小规模手算与 NumPy 实现。

1. 📜 科学史话：三幕剧（背景、危机与大师破局）

🎬 第一幕 · 时代背景：点积注意力的朴素直觉

在定义了 $Q$ 和 $K$ 之后，最直观的相似度计算就是向量点积 $S = Q \cdot K^T$：两个向量方向越一致，点积越大，分配的 Softmax 注意力权重就越高。

💥 第二幕 · 遭遇危机：维度暴涨引发的“Softmax 梯度荒漠”

然而，当大模型将特征维度 $d_k$ 从 16 扩展到 64、128 时，一个致命的统计学问题爆发了：
假设 $Q$ 和 $K$ 的分量是均值为 0、方差为 1 的独立随机变量，它们的点积 $\sum_{i=1}^{d_k} q_i k_i$ 的方差将线性扩大为 $d_k$（标准差为 $\sqrt{d_k} \approx 11.3$）！
点积结果动辄达到几十甚至上百。
当这么大的数值送入 Softmax 时，输出概率会极端二极化为极其尖锐的 0 和 1，Softmax 的导数瞬间归零（落入指数饱和区），反向传播梯度彻底消失！整个模型完全无法训练！

💡 第三幕 · 大师破局：2017 年 Vaswani 的“除以 $\sqrt{d_k}$”缩放神来之笔

2017 年，Ashish Vaswani 等人在公式中轻轻加入了一个缩放因子：除以 $\sqrt{d_k}$！ $$\text{Attention}(Q, K, V) = \text{softmax}\left( \frac{Q K^T}{\sqrt{d_k}} \right) V$$ 这个极简的缩放将方差精准拉回了完美的 $1.0$，彻底消除了 Softmax 梯度饱和问题，让千亿规模深层 Transformer 的稳定收敛成为可能！

2. 核心数学公式拆解

$$\text{Attention}(Q, K, V) = \underbrace{\text{softmax}\left( \frac{\overbrace{Q \times K^T}^{\text{1. 点积打分 S}}}{\underbrace{\sqrt{d_k}}_{\text{2. 尺度缩放}}} \right)}_{\text{3. 归一化注意力权重 A}} \times \underbrace{V}_{\text{4. 加权聚合}}$$

5. Python / NumPy 极简代码实现

import numpy as np

def scaled_dot_product_attention(Q: np.ndarray, K: np.ndarray, V: np.ndarray):
    d_k = Q.shape[-1]
    scores = np.matmul(Q, K.swapaxes(-1, -2)) / np.sqrt(d_k)
    exp_scores = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
    attn_weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)
    output = np.matmul(attn_weights, V)
    return output, attn_weights

Q_test = np.array([[1.0, 0.0], [0.0, 2.0]])
K_test = np.array([[1.0, 1.0], [0.0, 1.0]])
V_test = np.array([[10.0, 0.0], [0.0, 20.0]])
out, weights = scaled_dot_product_attention(Q_test, K_test, V_test)
print("注意力权重 A:\n", np.round(weights, 3))
print("输出 Y:\n", np.round(out, 2))

6. 打开黑盒：真实工程细节 (FlashAttention 思想萌芽)

标准 Attention 的内存致命伤：
中间矩阵 $S$ 和 $A$ 的形状为 $[B, H, L, L]$。
当上下文长度 $L=32768$（32k）时，仅存放一个中间注意力矩阵就需要 4GB 显存！
FlashAttention 巧妙利用分块在线 Softmax 算法，完全不在显存中保存 $S$ 和 $A$，直接在 SRAM 寄存器中一步算出最终输出 $Y$！

7. 动手实验与思考题

思考题：
如果将两个完全相同的序列送入 Attention，权重矩阵 $A$ 的对角线元素一定最大吗？
提示：不一定！点积的大小取决于向量的夹角和模长。如果某个 Token 的 Key 模长极大且方向契合，它可能会吸引全序列大部分的注意力。
