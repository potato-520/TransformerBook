3.4 残差连接与 FFN 记忆网络 (Residual Connection & FFN)

本节目标：理解 $X + \text{SubLayer}(X)$ 为什么被称为深层梯度的“高速公路”，掌握前馈神经网络（FFN / MLP）在大模型中扮演的“事实知识存储库与非线性升维”核心职能。

1. 残差连接（Residual Connection）解决什么问题？

当神经网络层数达到数十层甚至上百层时，反向传播的梯度需要连续乘以几十个权重矩阵 $\prod_{l=1}^L W_l$。
如果矩阵特征值稍小于 1，梯度就会指数级衰减至 0（梯度消失）。
残差连接通过在子层旁边并联一条无损直通通路（Identity Shortcut）： $$Y = X + \text{SubLayer}(X)$$ 求导时，$\frac{\partial Y}{\partial X} = I + \frac{\partial \text{SubLayer}(X)}{\partial X}$。其中的常数项 $1.0$ 保证了梯度可以直接无损跨层回传到最浅层！

2. FFN（前馈网络）在大模型中的核心角色

在 Transformer Block 中，注意力层负责“Token 之间的上下文通信”，而 FFN（Feed-Forward Network）则负责“单个 Token 内部的深层知识提炼与非线性升维”：

现代大模型 SwiGLU FFN 结构（LLaMA-3 标准）：
$$\text{SwiGLU}(x) = (\text{Linear}_1(x) \odot \text{SiLU}(\text{Linear}_2(x))) \times W_{down}$$ 特征维度通常先膨胀升维到原维度的 $\frac{8}{3} \times D_{model}$（例如从 4096 维升到 14336 维），经过门控激活后再投影降维回 4096 维。大模型中 60%~70% 的参数量都集中在 FFN 层中！

4. Python / NumPy 现代 SwiGLU FFN 实现

import numpy as np

class SwiGLUFFN:
    def __init__(self, d_model=4096, hidden_dim=14336):
        self.w_gate = np.random.randn(d_model, hidden_dim) * 0.02
        self.w_up   = np.random.randn(d_model, hidden_dim) * 0.02
        self.w_down = np.random.randn(hidden_dim, d_model) * 0.02

    def forward(self, x):
        # 1. 门控通路
        gate = np.dot(x, self.w_gate)
        silu_gate = gate / (1.0 + np.exp(-gate))
        
        # 2. 上投影通路
        up = np.dot(x, self.w_up)
        
        # 3. 逐元素相乘门控融合
        hidden = silu_gate * up
        
        # 4. 下投影降维回 d_model
        return np.dot(hidden, self.w_down)

ffn = SwiGLUFFN(d_model=64, hidden_dim=172)
fake_x = np.random.randn(2, 4, 64)
ffn_out = ffn.forward(fake_x)
block_out = fake_x + ffn_out

print("FFN 输出 Shape:", ffn_out.shape)
print("残差组合后 Shape:", block_out.shape)

学术界前沿共识：
近年大模型可解释性研究（如 ROME 论文）证明：Transformer 的自注意力层主要负责动态语境重路由，而大模型的静态世界知识（如“法国的首都是巴黎”、“C语言之父是丹尼斯·里奇”）大部分被持久化编码存储在 FFN 层的神经元权重中（类似于 Key-Value 记忆网络）！
