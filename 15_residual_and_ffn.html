3.4 残差连接与 FFN 记忆网络 (Residual Connection & FFN)

本节核心认知目标：
理解 $X + \text{SubLayer}(X)$ 为什么被称为深层梯度的“高速公路”，掌握前馈神经网络（FFN / MLP）在大模型中扮演的“事实知识存储库与非线性升维”核心职能。

1. 📜 科学史话：三幕剧（背景、危机与大师破局）

🎬 第一幕 · 时代背景：何恺明 ResNet 的“恒等残差高速公路”

2015 年，华人青年科学家何恺明提出了震惊世界的 ResNet（残差网络）：通过在子层旁并联一条无损直通通路 $Y = X + F(X)$，使梯度求导时自然包含常数项 $+1.0$，彻底打破了 20 层以上网络必崩的死咒，一举将网络堆叠到了 152 层！

💥 第二幕 · 遭遇危机：普通 ReLU FFN 在海量知识存储中的瓶颈

在早期 Transformer 中，FFN 仅使用最简单的两层线性投影 + ReLU。
当大模型规模扩展到数十亿参数时，研究发现普通 FFN 对世界事实知识的记忆效率低下，容易出现知识混淆与遗忘。

💡 第三幕 · 大师破局：Noam Shazeer 的 SwiGLU 门控前馈网络

2020 年，Google 顶尖科学家 Noam Shazeer 提出了 SwiGLU 门控前馈网络： $$\text{SwiGLU}(x) = (\text{Linear}_1(x) \odot \text{SiLU}(\text{Linear}_2(x))) \times W_{down}$$ 通过增加一路门控通路（Gating Unit），让网络能以极高精度选择性记忆和检索事实知识。
现代大模型（LLaMA / Qwen）中，超过 60%~70% 的模型参数都集中在 SwiGLU FFN 中，它成为了大模型名副其实的“世界事实知识记忆库”！

3. Python / NumPy 现代 SwiGLU FFN 实现

import numpy as np

class SwiGLUFFN:
    def __init__(self, d_model=64, hidden_dim=172):
        self.w_gate = np.random.randn(d_model, hidden_dim) * 0.02
        self.w_up   = np.random.randn(d_model, hidden_dim) * 0.02
        self.w_down = np.random.randn(hidden_dim, d_model) * 0.02

    def forward(self, x):
        gate = np.dot(x, self.w_gate)
        silu_gate = gate / (1.0 + np.exp(-gate))
        up = np.dot(x, self.w_up)
        return np.dot(silu_gate * up, self.w_down)

ffn = SwiGLUFFN(d_model=64, hidden_dim=172)
fake_x = np.random.randn(2, 4, 64)
print("SwiGLU FFN 输出 Shape:", ffn.forward(fake_x).shape)
