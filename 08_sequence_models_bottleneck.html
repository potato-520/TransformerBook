1.3 传统序列模型瓶颈 (RNN / LSTM Bottleneck)

本节核心认知目标：
理解在 2017 年 Transformer 诞生前，统治 NLP 的循环神经网络（RNN/LSTM）的核心工作机制，透视其“串行时钟依赖”与“固定维度记忆瓶颈”两大致命软肋，理解为什么 Transformer 的全并行架构是历史的必然。

1. 📜 科学史话：三幕剧（背景、危机与大师破局）

🎬 第一幕 · 时代背景：2014~2016 年 LSTM 统治序列霸权

在长达数年的时间里，以 RNN（循环神经网络） 和 LSTM（长短期记忆网络） 为代表的序列模型，是自然语言翻译、语音识别的绝对霸主。
它的设计哲学非常直观：人类看书是一个字一个字从左到右阅读的，所以模型维护一个隐藏状态向量 $h_t$（类似于人的短期记忆），读入一个新词就更新一次记忆： $$h_t = \tanh(W x_t + U h_{t-1})$$

💥 第二幕 · 遭遇危机：GPU 算力饥渴与长程记忆遗忘黑洞

然而，随着大模型对海量语料吞吐需求的爆发，RNN 撞上了两堵无法逾越的物理高墙：
1. 串行时钟依赖（Sequential Dependency）：计算第 1000 个词必须先等前 999 个词算完！现代 GPU 拥有上万个并行流处理器，但在 RNN 面前只能单核串行等待，硬件利用率（MFU）低至可怜的 5% 以下！
2. 固定维度信息瓶颈：无论是一篇 5000 字的长文还是一本小说，全部被强行压缩进一个固定大小的 512 维隐状态向量 $h_t$ 中，信息在漫长的时间步中被不断稀释冲刷，前面的信息彻底遗忘。

💡 第三幕 · 大师破局：2017 年“扔掉时钟”的范式大革命

2017 年，Google 团队的 8 位学者写下了名垂青史的论文 《Attention Is All You Need》！
他们做出了深度学习史上最激进的决定：“彻底扔掉所有的 RNN 循环连接！直接让序列中所有词在同一瞬间并行输入，通过矩阵广播同时计算任意两词之间的直接关联！”
这一革命将计算时间复杂度从 $O(L)$ 串行等待降维为 $O(1)$ 并行矩阵乘，彻底引爆了 GPU 的全部并行算力，开启了 Transformer 与现代大模型的新纪元！

2. RNN vs Transformer 拓扑与复杂度对比

对比维度 传统 RNN / LSTM 现代 Transformer (Self-Attention)
计算时序机制 严格串行，必须 $t-1 \to t$ 逐步推演 全序列一次性并行广播输入 (Matrix GEMM)
GPU 硬件利用率 极低（~5% MFU，频繁等待前步输出） 极高（~50%~70% MFU，满载矩阵乘）
长程关联路径长度 $O(L)$（随距离增加指数衰减） $O(1)$（任意两个词之间直通一步到达）

4. 打开黑盒：真实工程细节 (为什么硬件架构倒逼算法演进？)

硬件驱动的范式转移（Hardware Lottery）：
RNN 并不是在算法数学上被证明是错的，而是在现代 GPU 硬件架构面前败下阵来！
GPU 的天命就是做大规模张量并行矩阵乘（GEMM）。谁能把算法改造成纯矩阵乘的形式，谁就能吃到摩尔定律与 GPU 算力万倍爆发的红利！这正是自注意力机制（Self-Attention）横扫世界的最深层物理底层原因！

5. 动手实验与思考题

思考题：
如果我们将 RNN 和 Transformer 同时运行在单核单线程的极其古老的 CPU 上，两者的计算耗时还会有如此巨大的差距吗？
提示：在单核 CPU 上两者差距会缩小，甚至 RNN 会因为计算量 $O(L)$ 小于 Transformer 的 $O(L^2)$ 而在短文本上更快！正是 GPU 的数万核并行能力，决定了 Transformer 的绝对统治地位！
