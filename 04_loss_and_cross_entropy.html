0.4 Loss 测量尺与交叉熵 (Loss Functions & Cross-Entropy)

本节目标：理解神经网络是如何用数学标尺量化“预测错误程度”的，掌握回归任务中的 MSE 与大模型 Token 预测中的交叉熵（Cross-Entropy / NLL Loss）物理直觉。

1. 它解决什么问题？ (工程师视角黑盒引入)

在闭环控制系统（如 PID 控制器）中，我们必须计算目标值与当前反馈值的偏差 $e(t) = r(t) - y(t)$，才能驱动执行器进行修正。
在神经网络与大模型中，损失函数（Loss Function）就是这把核心的“误差测量尺”。它将高维度的预测张量与真实标签对比，输出一个单一的非负标量 Loss，作为后续反向传播调整参数的唯一目标。

2. 输入与输出 Tensor Shape

  • 预测 Logits $Z$：Shape: [B, V]。$B$ 为 Batch Size，$V$ 为词表大小（如 32000）。
  • 真实标签 Target $Y$：Shape: [B]。包含每个样本正确的 Token ID（整数索引）。
  • 输出 Loss $\mathcal{L}$：Shape: [1]（标量 float32）。

3. 交叉熵 Loss 的数学本质

交叉熵 Loss 本质上是负对数似然（Negative Log-Likelihood）： $$P_i = \text{Softmax}(Z)_i = \frac{e^{z_i}}{\sum_{j=1}^V e^{z_j}}$$ $$\mathcal{L} = -\log(P_{\text{target}})$$

5. 极小规模人工计算 (3 分类交叉熵手算)

已知条件：
真实标签 Target ID = 0（第 0 类为正确答案）
模型输出未归一化 Logits：$Z = \begin{bmatrix} 2.0 & 1.0 & 0.1 \end{bmatrix}$

第一步：Softmax 归一化为概率
$e^{2.0} \approx 7.389, \quad e^{1.0} \approx 2.718, \quad e^{0.1} \approx 1.105$
总和 $\sum = 7.389 + 2.718 + 1.105 = 11.212$
概率分布：$P = \begin{bmatrix} \frac{7.389}{11.212} & \frac{2.718}{11.212} & \frac{1.105}{11.212} \end{bmatrix} \approx \begin{bmatrix} 0.659 & 0.242 & 0.099 \end{bmatrix}$

第二步：计算负对数似然 Loss
目标类（index 0）的概率为 $P_0 = 0.659$
$$\mathcal{L} = -\ln(0.659) \approx 0.417$$

6. Python / NumPy 极简代码实现 (含数值防溢出技巧)

import numpy as np

def cross_entropy_loss(logits: np.ndarray, target_idx: int):
    # 1. 减去最大值防溢出
    shifted = logits - np.max(logits)
    exp_z = np.exp(shifted)
    probs = exp_z / np.sum(exp_z)
    
    # 2. 负对数似然
    p_target = probs[target_idx]
    loss = -np.log(p_target)
    return float(loss), probs

z_test = np.array([2.0, 1.0, 0.1])
target = 0
loss_val, p_dist = cross_entropy_loss(z_test, target)

print("概率分布:", np.round(p_dist, 4))
print(f"交叉熵 Loss: {loss_val:.4f}")
# 概率分布: [0.659  0.2424 0.0986], 交叉熵 Loss: 0.4170

7. 数学原理与物理直觉

为什么大模型预测 Token 一律采用交叉熵而不是均方误差（MSE）？

  • 信息论含义：交叉熵衡量的是用模型估计的分布 $P$ 去编码真实分布 $Q$ 时，平均所需要的额外比特数（Surprise / 困惑度 Perplexity 的对数形式）。
  • 梯度特性：$\frac{\partial \mathcal{L}}{\partial z_i} = P_i - Y_i$。其导数形式极其优雅直接——预测概率与真实标签的直接差值，完全没有 Sigmoid 在饱和区导致的梯度消失问题！

8. 打开黑盒：真实工程细节 (LogSumExp 技巧)

浮点数溢出与 LogSumExp：
在真实 CUDA 实现中，如果某个 Logit $z = 1000$，直接执行 exp(1000) 会在 IEEE-754 浮点数中瞬间产生 +inf，导致整个 Batch 的 Loss 变为 NaN。
PyTorch 的 F.cross_entropy 内部一律使用数学等价的 LogSumExp 技巧： $$\log \sum e^{z_i} = c + \log \sum e^{z_i - c} \quad (\text{取 } c = \max(z))$$
