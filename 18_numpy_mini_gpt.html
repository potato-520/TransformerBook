4.2 极简纯 NumPy GPT 推理引擎 (Mini GPT Engine in NumPy)

本节核心认知目标：
脱离任何 PyTorch / TensorFlow 依赖，使用不超过 200 行纯 Python + NumPy，从零手写一个可独立运行的完整 GPT Decoder 推理引擎，并在浏览器端单步断点执行验证！

1. 📜 科学史话：三幕剧（背景、危机与大师破局）

🎬 第一幕 · 时代背景：框架层层封装带来的“神话崇拜”

随着 HuggingFace、PyTorch、DeepSpeed 等重型框架的普及，大模型推理被封装为 model.generate() 这类一行命令。
这虽然极大方便了应用调用，但也让无数工程师对底层运行逻辑产生了某种不可知的“魔法崇拜”。

💥 第二幕 · 遭遇危机：脱离 GPU 集群即瘫痪的认知死角

很多初学者误以为大模型推理底层需要极其深奥不可测的操作系统特权，一旦离开庞大的 Python 运行时和几千个依赖包，就不知道一段文本是如何从矩阵一步步算出来的。

💡 第三幕 · 大师破局：安德烈·卡帕西（Karpathy）的极简底层还原

前 Tesla AI 总监、OpenAI 联合创始人安德烈·卡帕西（Andrej Karpathy）先后开源了 nanoGPT 与 llama2.c：
“大模型的推理本质，无非就是几百行纯 C 或 NumPy 初等矩阵乘累加的循环迭代！”
在本节中，我们将亲手运行这个 100 多行的纯 NumPy GPT 引擎，见证一个无依赖、完全透明的真正大模型是如何运转的！

2. 纯 NumPy 极简 GPT 完整实现

import numpy as np

class MiniGPT:
    def __init__(self, vocab_size=50, d_model=32, n_heads=2, n_layers=2):
        self.vocab_size = vocab_size
        self.d_model = d_model
        self.n_heads = n_heads
        self.n_layers = n_layers

        self.wte = np.random.randn(vocab_size, d_model) * 0.02
        self.wpe = np.random.randn(128, d_model) * 0.02

        self.blocks = []
        for _ in range(n_layers):
            self.blocks.append({
                'ln1_g': np.ones(d_model),
                'wq': np.random.randn(d_model, d_model) * 0.02,
                'wk': np.random.randn(d_model, d_model) * 0.02,
                'wv': np.random.randn(d_model, d_model) * 0.02,
                'wo': np.random.randn(d_model, d_model) * 0.02,
                'ln2_g': np.ones(d_model),
                'w_gate': np.random.randn(d_model, d_model * 4) * 0.02,
                'w_down': np.random.randn(d_model * 4, d_model) * 0.02,
            })
        self.ln_f_g = np.ones(d_model)
        self.lm_head = np.random.randn(d_model, vocab_size) * 0.02

    def _rmsnorm(self, x, gamma):
        rms = np.sqrt(np.mean(x ** 2, axis=-1, keepdims=True) + 1e-6)
        return (x / rms) * gamma

    def forward(self, token_ids):
        L = len(token_ids)
        x = self.wte[token_ids] + self.wpe[np.arange(0, L)]
        
        for b in self.blocks:
            norm_x = self._rmsnorm(x, b['ln1_g'])
            q = np.dot(norm_x, b['wq'])
            k = np.dot(norm_x, b['wk'])
            v = np.dot(norm_x, b['wv'])
            scores = np.matmul(q, k.T) / np.sqrt(self.d_model)
            mask = np.triu(np.ones_like(scores, dtype=bool), k=1)
            scores = np.where(mask, -1e9, scores)
            attn = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
            attn = attn / np.sum(attn, axis=-1, keepdims=True)
            x = x + np.dot(np.matmul(attn, v), b['wo'])
            
            norm_x2 = self._rmsnorm(x, b['ln2_g'])
            h = np.maximum(0, np.dot(norm_x2, b['w_gate']))
            x = x + np.dot(h, b['w_down'])
            
        x_norm = self._rmsnorm(x, self.ln_f_g)
        return np.dot(x_norm[-1], self.lm_head)

gpt = MiniGPT()
input_tokens = [1, 15, 28]
print("初始 Prompt:", input_tokens)
for step in range(3):
    logits = gpt.forward(input_tokens)
    next_token = int(np.argmax(logits))
    input_tokens.append(next_token)
    print(f"Step {step+1}: 预测下一个 Token = {next_token} -> 当前序列:", input_tokens)
