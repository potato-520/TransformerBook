2.3 多头注意力机制 (Multi-Head Attention, MHA)

本节目标：理解为什么单个 Attention 不够用，掌握多头注意力（MHA）的“特征子空间多路复用”思想，彻底吃透张量维度的切分（Split）、并行计算与合并重组（Concat & Projection）流水线。

1. 它解决什么问题？ (工程师视角黑盒引入)

在处理自然语言时，一个单词在句子中往往承担着多重不同的语境关系：

  • 语法依赖头（Head 1）：关注主谓宾搭配（例如 "The cat" 关注动词 "sat"）；
  • 指代消解头（Head 2）：关注代词指代（例如 "it" 锁定 "animal"）；
  • 时空因果头（Head 3）：关注时间与地点状语。

多头注意力（Multi-Head Attention）通过将总特征维度 $D_{model}$ 切分为 $H$ 个互不干扰的独立子空间（每个子空间维度 $d_k = D_{model} / H$），让各个 Head 能够并行关注不同维度的模式。

2. Tensor Shape 全链路流转轨迹

张量变形记（Tensor Reshape Pipeline）：
1. 输入张量 $X$：[B, L, D] (例如 Batch=2, SeqLen=512, Dim=4096)
2. 线性投影 QKV：[B, L, D] $\to$ 维度切分与转置：[B, H, L, d_k] (例如 Head=32, $d_k=128$)
3. 并行多头 Attention：$Q \times K^T \implies$ [B, H, L, L] $\times V \implies$ [B, H, L, d_k]
4. 多头拼接（Concat）：转置回 [B, L, H \cdot d_k] = [B, L, D]
5. 最终输出线性投影 $W_O$：[B, L, D] $\times [D, D] \implies$ [B, L, D]

4. Python / NumPy 极简多头注意力实现

import numpy as np

class MultiHeadAttention:
    def __init__(self, d_model=4096, n_heads=32):
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads  # 128
        
        self.W_q = np.random.randn(d_model, d_model) * 0.02
        self.W_k = np.random.randn(d_model, d_model) * 0.02
        self.W_v = np.random.randn(d_model, d_model) * 0.02
        self.W_o = np.random.randn(d_model, d_model) * 0.02

    def forward(self, x):
        B, L, D = x.shape
        
        # 1. 投影产生 Q, K, V
        q = np.dot(x, self.W_q)
        k = np.dot(x, self.W_k)
        v = np.dot(x, self.W_v)
        
        # 2. 变换形状切分多头: [B, L, H, d_k] -> [B, H, L, d_k]
        q = q.reshape(B, L, self.n_heads, self.d_k).transpose(0, 2, 1, 3)
        k = k.reshape(B, L, self.n_heads, self.d_k).transpose(0, 2, 1, 3)
        v = v.reshape(B, L, self.n_heads, self.d_k).transpose(0, 2, 1, 3)
        
        # 3. 缩放点积注意力 [B, H, L, L]
        scores = np.matmul(q, k.transpose(0, 1, 3, 2)) / np.sqrt(self.d_k)
        exp_s = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
        attn = exp_s / np.sum(exp_s, axis=-1, keepdims=True)
        
        # 4. 加权输出: [B, H, L, d_k]
        out_heads = np.matmul(attn, v)
        
        # 5. 拼接合并回 [B, L, D]
        concat_out = out_heads.transpose(0, 2, 1, 3).reshape(B, L, self.d_model)
        
        # 6. 最终输出投影
        final_output = np.dot(concat_out, self.W_o)
        return final_output

mha = MultiHeadAttention(d_model=64, n_heads=4)
fake_input = np.random.randn(2, 8, 64)
out = mha.forward(fake_input)
print("多头输出张量 Shape:", out.shape)

5. 打开黑盒：真实工程细节 (为什么各头不单独建矩阵？)

内存连续性与 Strided View：
在 C++ / PyTorch 源码中，分头操作完全不需要进行任何显存数据搬运（零拷贝）！
它仅仅是通过修改张量的步长（Strides）和视图（View），将连续的 4096 维浮点数组在逻辑上解释为 [32, 128] 的二维矩阵，从而保证了底层 GPU L1/L2 Cache 的极速行连续命中！

6. 动手实验与思考题

思考题：
保持总维度 $D_{model}=4096$ 不变，如果我们将头数 $H$ 从 32 头增加到 64 头（每个头的维度从 128 降到 64），注意力机制的理论计算量（FLOPs）会发生改变吗？
提示：不会改变！因为总计算量始终是 $O(B \cdot L^2 \cdot D_{model})$。但更多的 Head 会带来更丰富的特征子空间抽取能力。
