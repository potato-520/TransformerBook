3.1 位置编码与 RoPE (Positional Encoding & Rotary Embedding)

本节核心认知目标：
理解为什么 Attention 天生是无序的（集合运算），掌握从早期正余弦绝对位置编码到现代大模型（LLaMA/Qwen/Mistral）标配 RoPE（旋转位置编码）的数学演进与复数旋转几何直觉。

1. 📜 科学史话：三幕剧（背景、危机与大师破局）

🎬 第一幕 · 时代背景：Attention 的无序“词袋”本性与绝对编码

在丢弃了 RNN 的时钟推进后，自注意力机制变成了一种纯粹的集合操作（Set Operation）：打乱句中单词顺序，两两点积完全不变！
2017 年的经典 Transformer 采用绝对位置编码（Absolute PE）：构造一组正余弦波形向量 $P$，直接加在词向量上：$X_{pos} = X + P$。

💥 第二幕 · 遭遇危机：长上下文外推的“雪崩瘫痪”与相对距离丢失

然而，绝对位置编码很快暴露了致命软肋：
1. 外推性（Extrapolation）极差：如果模型在 2048 长度下训练，当输入 4096 长度的文本时，模型对后半段从未见过的位置向量毫无感知，直接胡言乱语；
2. 无法直接体现“相对距离”：在语言中，两个词之间相隔 3 个位置还是 50 个位置是核心关键，但绝对位置相加无法在点积中自然显现相对距离。

💡 第三幕 · 大师破局：2021 年苏剑林与复平面旋转（RoPE）的惊世推导

2021 年，中国青年学者苏剑林（追一科技）在博客“科学空间”中发布了划时代的 RoPE（Rotary Position Embedding，旋转位置编码）！
他没有在向量上做粗暴的加法，而是巧妙借助复数欧拉公式：将 2D 特征子平面上的 Query 和 Key 向量，按位置序号 $m$ 逆时针旋转 $m\theta$ 角度！
这一设计的数学神迹在于：旋转后的向量内积，完全只取决于两个词的相对距离 $(m - n)$！ $$\langle R_m \vec{q}, R_n \vec{k} \rangle = \vec{q}^T R_{n - m} \vec{k}$$ 由于无需额外加法、具备天然的相对衰减性与超强外推性，RoPE 瞬间征服了全球学术界与工业界，成为 LLaMA-1/2/3、Mistral、Qwen-2.5 等当代顶尖大模型的绝对世界标准！

2. 为什么 RoPE 如此神奇？ (相对位置内积恒等式)

复平面 2D 旋转公式： $$R_{\Theta, m} \cdot \vec{x} = \begin{pmatrix} \cos m\theta & -\sin m\theta \\ \sin m\theta & \cos m\theta \end{pmatrix} \begin{pmatrix} x_1 \\ x_2 \end{pmatrix}$$ 高维向量中，每相邻两个维度组成一个独立的 2D 旋转平面，频率 $\theta_i = 10000^{-2i/d}$ 由快到慢递减（类似于时钟的秒针、分针与时针）。

4. Python / NumPy 极简 RoPE 实现

import numpy as np

def apply_rope(x: np.ndarray, pos: int, base=10000.0) -> np.ndarray:
    dim = len(x)
    i = np.arange(0, dim, 2)
    theta = 1.0 / (base ** (i / dim))
    m_theta = pos * theta
    cos_m = np.cos(m_theta)
    sin_m = np.sin(m_theta)
    
    x_even = x[0::2]
    x_odd = x[1::2]
    rot_even = x_even * cos_m - x_odd * sin_m
    rot_odd = x_even * sin_m + x_odd * cos_m
    
    output = np.zeros_like(x)
    output[0::2] = rot_even
    output[1::2] = rot_odd
    return output

q = np.array([1.0, 0.0, 0.5, 0.5])
print("位置 0 旋转后:", apply_rope(q, pos=0))
print("位置 5 旋转后:", np.round(apply_rope(q, pos=5), 4))

5. 打开黑盒：真实工程细节 (YaRN 与 128k 上下文外推)

为什么 RoPE 能扩展到 128k 上下文？
通过调整基频 $base$（从 10,000 提升至 500,000，即 YaRN / NTK-aware RoPE），相当于降低了高频旋转速度，让模型在更稀疏的旋转角下识别更长远的位置距离，零成本实现上下文外推！

6. 动手实验与思考题

思考题：
RoPE 仅作用于 $Q$ 和 $K$ 张量，请问需要对 $V$（Value）张量执行 RoPE 旋转吗？为什么？
提示：不需要！因为 $V$ 代表的是纯粹的内容信息，位置偏置已经完全由 $Q$ 和 $K$ 的点积注意力权重 $A$ 所决定。
