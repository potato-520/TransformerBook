0.3 激活函数的本质 (Non-linearity & Activation Functions)

本节目标：从数学证明与信号处理双重视角，深刻理解为什么“没有激活函数，100 层线性网络依然等价于 1 层”，掌握 ReLU、GELU、SwiGLU 等现代大模型核心激活函数的本质。

1. 它解决什么问题？ (工程师视角黑盒引入)

假设我们堆叠了 3 层全连接层：$Y_1 = X W_1$，$Y_2 = Y_1 W_2$，$Y_3 = Y_2 W_3$。
代入展开得到：$Y_3 = ((X W_1) W_2) W_3 = X (W_1 W_2 W_3) = X W_{effective}$！
结论：纯线性矩阵相乘无论叠加多少层，最终都可以被单层矩阵等效替代！

为了让神经网络具备拟合任意复杂曲线（如折线、边界分段、逻辑门）的能力，必须在每两层矩阵乘法之间插入非线性激活函数 $\sigma(\cdot)$。

2. 输入与输出 Tensor Shape (逐元素操作)

激活函数是逐元素（Element-wise）独立作用的，因此张量形状完全保持不变： $$X \in \mathbb{R}^{B \times L \times D} \xrightarrow{\quad \sigma(\cdot) \quad} Y \in \mathbb{R}^{B \times L \times D}$$

3. 常见激活函数家族对比

激活函数 数学公式 输出范围 在现代大模型中的应用
ReLU $\max(0, x)$ $[0, +\infty)$ 经典 CNN / 传统深度学习标配
GELU $x \cdot \Phi(x) \approx 0.5x(1 + \tanh(\sqrt{2/\pi}(x + 0.044715x^3)))$ $[-0.17, +\infty)$ BERT / GPT-2 / GPT-3 / ViT 标配
SiLU (Swish) $x \cdot \text{sigmoid}(x)$ $[-0.278, +\infty)$ LLaMA-1/2/3 / Qwen / Mistral (SwiGLU)
Sigmoid $\frac{1}{1 + e^{-x}}$ $(0, 1)$ 二分类输出层 / 门控机制 (Gate)

5. 极小规模人工计算 (向量数值对比)

输入向量：$X = \begin{bmatrix} -2.0 & 0.0 & 2.0 \end{bmatrix}$

计算各激活函数输出：
1. ReLU: $\max(0, X) = \begin{bmatrix} 0.0 & 0.0 & 2.0 \end{bmatrix}$
2. Sigmoid: $\frac{1}{1 + e^{-X}} = \begin{bmatrix} \frac{1}{1 + e^2} & \frac{1}{1+1} & \frac{1}{1+e^{-2}} \end{bmatrix} \approx \begin{bmatrix} 0.1192 & 0.5000 & 0.8808 \end{bmatrix}$
3. GELU: $(-2.0)\cdot \Phi(-2.0) \approx -2.0 \times 0.0228 = -0.0456$；$0 \cdot \Phi(0)=0.0$；$2.0 \cdot \Phi(2.0) \approx 2.0 \times 0.9772 = 1.9544$。
$\text{GELU}(X) \approx \begin{bmatrix} -0.0456 & 0.0000 & 1.9544 \end{bmatrix}$

6. Python / NumPy 极简代码实现

import numpy as np

def relu(x: np.ndarray) -> np.ndarray:
    return np.maximum(0, x)

def gelu(x: np.ndarray) -> np.ndarray:
    return 0.5 * x * (1.0 + np.tanh(np.sqrt(2.0 / np.pi) * (x + 0.044715 * np.power(x, 3))))

def silu(x: np.ndarray) -> np.ndarray:
    return x / (1.0 + np.exp(-x))

test_x = np.array([-2.0, 0.0, 2.0], dtype=np.float32)
print("输入:", test_x)
print("ReLU:", relu(test_x))
print("GELU:", np.round(gelu(test_x), 4))
print("SiLU:", np.round(silu(test_x), 4))

7. 数学原理与物理直觉

为什么现代大模型抛弃了 ReLU，全面转向 GELU 和 SwiGLU？

  • 概率自适应门控：GELU 可以理解为“输入 $x$ 越大，该通道越有概率通过（乘以 1），输入越小，越大概率被阻断（乘以 0）”。
  • 全阶可导与平滑性：ReLU 在 $x=0$ 处导数不可导（跳跃），在深层大模型反向传播中会导致梯度震荡；而 GELU / SiLU 处处光滑，极大提升了深层网络的收敛稳定性。

8. 打开黑盒：真实工程细节 (Memory-bound 与算子融合)

GPU 显存带宽瓶颈：
激活函数属于经典的 Memory-bound（内存带宽受限） 算子（计算密度极低，需要从 HBM 显存读入数据、算一次、再写回 HBM）。
在现代 PyTorch 2.0（torch.compile）或 CUDA 优化中，通常会将线性层投影与激活函数做 Kernel Fusion（算子融合），直接在 SRAM/寄存器中完成激活计算，彻底省去一次昂贵的全局显存读写！
