0.3 激活函数的本质 (Activation Functions: ReLU, GELU, SiLU)

本节核心认知目标：
理解为什么没有激活函数的深层网络在数学上等价于单层薄网，掌握深度学习从早期的 Sigmoid / Tanh 梯度消失泥潭，到 ReLU 粗暴破局，再到现代大模型全面普及平滑门控激活函数（GELU / SiLU）的演进史诗。

1. 📜 科学史话：三幕剧（背景、危机与大师破局）

🎬 第一幕 · 时代背景：模仿生物平滑放电的 Sigmoid 黄金时代

在 20 世纪 80~90 年代，学术界普遍坚信：激活函数必须模仿生物神经元的“S 型放电曲线”，具有连续光滑、处处可导的优美数学特性。
于是，以 $\sigma(x) = \frac{1}{1 + e^{-x}}$ 为代表的 Sigmoid 和 Tanh 统治了整个神经网络领域。

💥 第二幕 · 遭遇危机：多层连乘引发的“梯度消失大雪崩”

然而，当工程师试图将网络加深到 4 层、5 层以上时，灾难降临了：
Sigmoid 函数的导数最大值只有可怜的 $0.25$（当输入绝对值稍大时，导数甚至迅速趋近于 0）。在反向传播中，梯度每穿过一层就要乘以一个小于 $0.25$ 的数： $$\text{梯度衰减} \approx (0.25)^5 \approx 0.00097$$ 传到最前面的输入层时，梯度几乎彻底归零！底层神经元完全无法获得任何学习信号，深层神经网络陷入彻底瘫痪。

💡 第三幕 · 大师破局：辛顿的“粗暴折线”与现代平滑门控革命

2010 年，Geoffrey Hinton 与学生 Alex Krizhevsky 抛弃了所有优美平滑的指数曲线，粗暴地采用了一条极其简单的折线： $$\text{ReLU}(x) = \max(0, x)$$ 在正半轴，它的导数永远恒等于 $1.0$！梯度即使穿过 100 层也不会衰减半点，直接造就了 2012 年 ImageNet 夺冠的 AlexNet，开启了现代深度学习时代！
随后，Hendrycks 等人在 2016 年提出结合概率门控的 GELU（成为 GPT / BERT 标配），Google 团队在 2017 年搜索出 SiLU / Swish（成为 LLaMA / Qwen 标配），将神经网络的表达能力推向巅峰！

2. 常见激活函数数学形态与导数对比

激活函数 数学公式 输出范围 正半轴导数 代表模型
Sigmoid $\sigma(x) = \frac{1}{1 + e^{-x}}$ $(0, 1)$ $\le 0.25$ (极易梯度消失) 早期二分类网络
ReLU $\max(0, x)$ $[0, +\infty)$ 恒等于 1.0 ResNet, AlexNet
GELU $x \cdot \Phi(x) \approx x \cdot \sigma(1.702 x)$ $(-0.17, +\infty)$ 平滑渐近 1.0 GPT-2, GPT-3, BERT
SiLU (Swish) $x \cdot \sigma(x) = \frac{x}{1 + e^{-x}}$ $(-0.28, +\infty)$ 平滑渐近 1.0 LLaMA-1/2/3, Mistral, Qwen

4. Python / NumPy 极简实现

import numpy as np

def relu(x):
    return np.maximum(0, x)

def silu(x):
    return x / (1.0 + np.exp(-x))

def gelu(x):
    return 0.5 * x * (1.0 + np.tanh(np.sqrt(2.0 / np.pi) * (x + 0.044715 * (x ** 3))))

x_test = np.array([-2.0, -0.5, 0.0, 0.5, 2.0])
print("输入信号:", x_test)
print("ReLU 输出:", np.round(relu(x_test), 3))
print("SiLU 输出:", np.round(silu(x_test), 3))
print("GELU 输出:", np.round(gelu(x_test), 3))

5. 打开黑盒：真实工程细节 (Memory-bound 与算子融合)

为什么激活函数在 GPU 上是 Memory-bound 访存瓶颈？
像 SiLU 这样的激活函数，虽然只需几个浮点周期，但必须对张量的每个元素逐一读取显存并写回（内存带宽受限）。
现代框架通过 Kernel Fusion（算子融合，如 Triton / Flash-Linear），将上一步矩阵乘法的输出直接缓存在片上 SRAM 寄存器中执行 SiLU，完全不经过显存中转，提速超过 50%！

6. 动手实验与思考题

思考题：
为什么现代 LLM（如 LLaMA-3）绝大部分放弃了普通的 ReLU，改用带有平滑下凹小负值的 SiLU？
提示：ReLU 在 $x < 0$ 时导数严格为 0，可能导致一部分神经元“永久坏死（Dead ReLU）”。而 SiLU 具有平滑非单调的负极小值，保留了微弱的探索梯度。
