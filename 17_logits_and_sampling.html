4.1 Logits 映射与采样策略 (Logits, Softmax & Sampling)

本节核心认知目标：
理解大模型是如何将最后一层 Block 输出的抽象隐藏状态（Hidden State）映射回包含数万个词的词表分布，掌握 Temperature、Top-k、Top-p（核采样）的数学机理与工程实现。

1. 📜 科学史话：三幕剧（背景、危机与大师破局）

🎬 第一幕 · 时代背景：贪婪解码（Greedy Search）的确定性时代

在语言生成初期，人们最直接的做法是贪婪搜索（Greedy Search）：每一步计算完词表得分后，直接挑 Logit 最大的那个词（$\text{argmax}$）作为输出。

💥 第二幕 · 遭遇危机：“车轱辘话死循环”与创造力的彻底窒息

然而，贪婪搜索很快产生了严重的生成退化：
模型生成的语言极其生硬单一，并且一旦某句话中出现了重复词，自注意力权重就会锁死在该词上，导致模型陷入可怕的“车轱辘话无限死循环”！而如果完全随机采样，又会经常抽到低概率的乱码生僻词。

💡 第三幕 · 大师破局：2019 年霍尔茨曼（Holtzman）与 Top-p 核采样

2019 年，华盛顿大学的 Ari Holtzman 等人提出了划时代的 Top-p (Nucleus，核采样) 算法，并结合统计物理中的 Temperature（温度系数）：
- 动态截断：不要固定挑前 K 个词，而是按概率从大到小累加，只保留累积概率达到 $p$（如 0.9）的头部“核心词汇池”；
- 随境而变：当模型非常确信时（如“人工智能”后面接“技术”），候选池可能只有 1~2 个词；当模型处于开放语境时，候选池自动扩大到几十个词！
配合 Temperature 控制平滑度，大模型终于第一次展现出既逻辑严谨又妙趣横生的人类般自然表达！

3. Python / NumPy 工业级采样器实现

import numpy as np

def sample_next_token(logits: np.ndarray, temperature=0.7, top_p=0.9) -> int:
    if temperature > 0:
        logits = logits / temperature
    else:
        return int(np.argmax(logits))
    
    probs = np.exp(logits - np.max(logits))
    probs = probs / np.sum(probs)
    
    sorted_indices = np.argsort(probs)[::-1]
    sorted_probs = probs[sorted_indices]
    cumulative_probs = np.cumsum(sorted_probs)
    
    cutoff_index = np.searchsorted(cumulative_probs, top_p)
    valid_indices = sorted_indices[:cutoff_index + 1]
    valid_probs = probs[valid_indices]
    valid_probs = valid_probs / np.sum(valid_probs)
    
    return int(np.random.choice(valid_indices, p=valid_probs))

test_logits = np.array([4.5, 3.2, 1.8, 0.5, -1.0])
print("采样出的 Next Token ID:", sample_next_token(test_logits, 0.7, 0.9))

4. 打开黑盒：真实工程细节 (Repetition Penalty 重复惩罚)

打断死循环：
推理引擎中通常会引入 Repetition Penalty（重复惩罚，如 1.15）：如果某个 Token 在过去 64 步中出现过，将其对应的 Logit 强制除以该惩罚因子，有效打破重复怪圈！
