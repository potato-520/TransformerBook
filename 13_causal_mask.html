3.2 Causal Mask 因果掩码 (Causal Masking)

本节核心认知目标：
理解为什么自回归大模型在生成文本时“绝对不能偷看未来”，掌握上三角 $-\infty$ 掩码矩阵的构建原理与 Softmax 归零机制。

1. 📜 科学史话：三幕剧（背景、危机与大师破局）

🎬 第一幕 · 时代背景：2018 年 BERT 的双向狂欢

2018 年，Google 推出 BERT 模型，采用双向 Encoder 架构：每个词都可以同时看到上下文的所有词，并在填空题（Masked LM）任务上横扫各大榜单，双向注意力被视为王道。

💥 第二幕 · 遭遇危机：双向模型在生成任务上的“作弊瘫痪”

然而，当人们试图用双向模型写小说、写代码时，遇到了根本性的逻辑死锁：
在生成第 $t$ 个词时，后面的词根本还没有诞生！如果训练时允许模型双向看全句，模型就会走捷径“偷看答案”，在真实推理时面对未知未来彻底崩溃。

💡 第三幕 · 大师破局：OpenAI GPT 的 Decoder-Only 孤勇者之路与因果掩码

在全行业追捧 BERT 双向架构时，OpenAI 的 Alec Radford 等人坚守 Decoder-Only 架构：
他们使用极其优雅的下三角因果掩码（Causal Mask）——在训练并行计算矩阵乘的同时，强行将未来词的注意力打分置为 $-\infty$（经过 Softmax 后权重精确归零）！
这一设计完美统一了“训练时的全矩阵极速并行”与“生成时的严格单向因果”，最终造就了 ChatGPT 与当今大模型的统一天下！

2. 数学构造：上三角 $-\infty$ 掩码矩阵

$$M_{ij} = \begin{cases} 0, & i \ge j \quad (\text{允许查看历史}) \\ -\infty, & i < j \quad (\text{严格屏蔽未来}) \end{cases}$$ $$\text{softmax}(S + M)_{ij} \implies \text{当 } i < j \text{ 时，} e^{-\infty} = 0 \quad (\text{权重精确为 } 0.000)$$

4. Python / NumPy 极简因果掩码实现

import numpy as np

def apply_causal_mask(scores: np.ndarray) -> np.ndarray:
    seq_len = scores.shape[-1]
    mask = np.triu(np.ones((seq_len, seq_len), dtype=bool), k=1)
    masked_scores = np.where(mask, -1e9, scores)
    exp_s = np.exp(masked_scores - np.max(masked_scores, axis=-1, keepdims=True))
    return exp_s / np.sum(exp_s, axis=-1, keepdims=True)

raw_scores = np.ones((4, 4)) * 2.0
print("掩码后注意力权重 A:\n", np.round(apply_causal_mask(raw_scores), 3))

5. 打开黑盒：真实工程细节 (FlashAttention 硬件因果剔除)

算力翻倍福利：
在因果掩码下，整个 $L \times L$ 注意力矩阵的上半部分完全不需要参与实际计算。
FlashAttention 在 CUDA 底层直接跳过了上三角全部 Tile 矩阵块的加载与计算，使前向注意力计算速度直接翻倍！
