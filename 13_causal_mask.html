3.2 Causal Mask 因果掩码 (Causal Masking)

本节目标：理解为什么 Decoder-Only 大模型在生成文本时“绝对不能偷看未来”，掌握上三角 $-\infty$ 掩码矩阵的构建原理与 Softmax 归零机制。

1. 它解决什么问题？ (工程师视角黑盒引入)

现代主流大模型（GPT-4、LLaMA-3、Qwen-2.5）全部属于 **Decoder-Only 自回归架构**。
自回归生成的本质是：根据已经生成的历史单词 $[x_1, x_2, \dots, x_t]$，预测下一个单词 $x_{t+1}$。
在模型训练阶段，整句话是一次性并行输入进 GPU 的。如果不做任何约束，第 $t$ 个词就能在注意力矩阵中“偷看”到第 $t+1$ 个词的真实答案！
后果：模型会走捷径死记硬背答案，在真实推理生成时彻底瘫痪！

2. 数学构造：上三角 $-\infty$ 掩码矩阵

为了在并行计算的同时彻底阻断“未来信息泄漏”，我们在注意力打分矩阵 $S = \frac{QK^T}{\sqrt{d_k}}$ 上直接叠加一个下三角因果掩码矩阵 $M$： $$M_{ij} = \begin{cases} 0, & i \ge j \quad (\text{当前与历史 Token，允许交互}) \\ -\infty, & i < j \quad (\text{未来 Token，严格屏蔽}) \end{cases}$$

叠加后送入 Softmax： $$\text{softmax}(S + M)_{ij} = \frac{e^{S_{ij} + M_{ij}}}{\sum_k e^{S_{ik} + M_{ik}}} \implies \text{当 } i < j \text{ 时，} e^{-\infty} = 0 \quad (\text{权重精确为 } 0.000)$$

4. Python / NumPy 极简因果掩码实现

import numpy as np

def apply_causal_mask(scores: np.ndarray) -> np.ndarray:
    seq_len = scores.shape[-1]
    
    # 1. 构造上三角为 True 的布尔矩阵
    mask = np.triu(np.ones((seq_len, seq_len), dtype=bool), k=1)
    
    # 2. 将未来位置填充为 -inf
    masked_scores = np.where(mask, -1e9, scores)
    
    # 3. Softmax 归一化
    exp_s = np.exp(masked_scores - np.max(masked_scores, axis=-1, keepdims=True))
    attn_weights = exp_s / np.sum(exp_s, axis=-1, keepdims=True)
    return attn_weights

raw_scores = np.ones((4, 4)) * 2.0
masked_attn = apply_causal_mask(raw_scores)
print("应用因果掩码后的注意力权重矩阵 A:\n", np.round(masked_attn, 3))

5. 打开黑盒：真实工程细节 (FlashAttention 硬件因果剔除)

算力翻倍福利：
在因果掩码下，整个 $L \times L$ 注意力矩阵的上半部分（右上角）是完全不需要参与实际计算的！
FlashAttention 在 CUDA 底层直接跳过了上三角全部 Tile 矩阵块的加载与计算，使得 Decoder-Only 架构的前向注意力计算速度直接提升了整整一倍！
