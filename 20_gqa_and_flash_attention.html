4.4 GQA 与 FlashAttention 思想 (GQA & FlashAttention)

本节目标：理解现代大模型是如何在架构层（GQA 分组查询注意力）与硬件层（FlashAttention IO 优化）两路并发，彻底攻克长上下文显存爆炸与 GPU 访存带宽瓶颈的。

1. 架构演进：MHA $\to$ MQA $\to$ GQA

  • MHA (Multi-Head Attention, 2017)：每个 Query 头配 1 个独立的 Key 和 Value 头（KV 头数 = 32）。缺点：KV Cache 极其庞大。
  • MQA (Multi-Query Attention, 2019)：所有 Query 头强行共享 1 个单调的 Key 和 Value 头（KV 头数 = 1）。优点：显存暴降 32 倍；缺点：模型容量与表达精度受损。
  • GQA (Grouped-Query Attention, 现代主流 LLaMA-3 / Mistral 标配)：折中方案！例如 32 个 Query 头分为 8 组，每 4 个 Query 头共享 1 个 KV 头（KV 头数 = 8）。既保全了极高的语义精度，又将 KV 显存开销直接削减为原来的 $\frac{1}{4}$！

2. FlashAttention 核心哲学：向 GPU 存储层级要性能

GPU 的金字塔存储瓶颈：
SRAM 片上高速缓存（容量极小 ~数十KB，但速度高达 19 TB/s） $\gg$ HBM 全局大显存（容量大 80GB，但速度仅 2~3 TB/s，慢了将近 10 倍！）。
传统 Attention 频繁将超大 $L \times L$ 中间矩阵从 SRAM 写回 HBM 显存，导致 GPU 核心长时间卡在内存读写等待上。
FlashAttention 核心思想：分块切片（Tiling）+ 在线 Softmax 动态更新（Online Softmax）！
将 $Q, K, V$ 切成一个个小 Tile 完全装入 SRAM，在高速缓存内一步算出局部的 Attention 聚合结果，**全程完全不生成、不写回庞大的 $L \times L$ 注意力矩阵！**

4. 打开黑盒：真实工程细节 (FlashAttention-2 & FlashAttention-3)

硬件演进与算子重塑：
FlashAttention 的作者 Tri Dao 在 2023~2024 年相继推出了 FlashAttention-2 与 3，针对 NVIDIA Hopper 架构（H100/H200）的 Tensor Memory Accelerator (TMA) 和异步流水线重写了底层 Warp 级调度，实现了高达 75% 的硬件极限利用率（浮点吞吐接近 700 TFLOPS）！
