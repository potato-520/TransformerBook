1.2 Embedding 嵌入层与语义空间 (Embedding Layer & Vector Space)

本节目标：破除 Embedding 的高深神秘感，从嵌入式查表（Lookup Table / RAM 读取）视角理解其本质，掌握高维密集向量的几何加减与余弦相似度度量。

1. 它解决什么问题？ (工程师视角黑盒引入)

Token ID 只是一个孤立的整数编号（例如 apple=1024，orange=1025）。
在离散的整数之间，加减乘除毫无数学意义（例如 $1024 + 1 = 1025$ 并不代表苹果加上 1 变成橙子）。
Embedding 嵌入层的作用，就是为每个 Token 赋予一个高维度的稠密浮点向量（如 4096 维），让语义相近的词在高维几何空间中靠得更近。

2. 输入与输出 Tensor Shape (查表本质)

  • 输入 Token ID 矩阵 $X$：Shape: [B, L]（整数索引，数据类型 int64）。
  • Embedding 权重查找表 $E$：Shape: [V, D_{model}]（$V$ 是词表大小，$D_{model}$ 是特征维度）。
  • 输出张量 $H$：Shape: [B, L, D_{model}]（浮点数张量，float32 / bfloat16）。

3. 几何物理直觉：高维空间中的语义加减法

著名的向量算术奇迹：
$$\vec{v}(\text{"King"}) - \vec{v}(\text{"Man"}) + \vec{v}(\text{"Woman"}) \approx \vec{v}(\text{"Queen"})$$ 在训练良好的 Embedding 空间中，特定方向的平移向量代表了明确的语义属性（例如“性别向量”、“时态向量”、“资本与国家关系向量”）。

5. 极小规模人工计算 (Embedding 查表走查)

已知条件：
词表大小 $V=4$，特征维度 $D_{model}=3$。
Embedding 权重矩阵 $E$（本质就是一张二维浮点数组）： $$E = \begin{bmatrix} \text{ID 0:} & 0.1 & -0.5 & 0.8 \\ \text{ID 1:} & 1.2 & 0.0 & -0.3 \\ \text{ID 2:} & -0.9 & 0.4 & 0.7 \\ \text{ID 3:} & 0.5 & 0.5 & 0.0 \end{bmatrix}_{4 \times 3}$$ 输入句子序列的 Token IDs：$X = \begin{bmatrix} 2 & 0 & 3 \end{bmatrix}$ (长度 $L=3$)

查表输出矩阵 $H$（直接读取第 2、0、3 行）： $$H = \begin{bmatrix} E[2] \\ E[0] \\ E[3] \end{bmatrix} = \begin{bmatrix} -0.9 & 0.4 & 0.7 \\ 0.1 & -0.5 & 0.8 \\ 0.5 & 0.5 & 0.0 \end{bmatrix}_{3 \times 3}$$

6. Python / NumPy 极简代码实现

import numpy as np

# 1. 创建 Embedding 权重查找表 (Vocab=1000, Dim=4096)
vocab_size = 1000
d_model = 4096
embedding_table = np.random.randn(vocab_size, d_model).astype(np.float32)

# 2. 输入 Batch=2, SeqLen=3 的 Token ID 数组
token_ids = np.array([[10, 42, 99],
                      [5,  18, 500]], dtype=np.int64)

# 3. 查表操作 (NumPy 数组高级花式索引)
# 等价于 PyTorch 的 nn.Embedding(vocab_size, d_model)(token_ids)
embedded_tensor = embedding_table[token_ids]

print("输出张量 Shape:", embedded_tensor.shape)  # 输出: (2, 3, 4096)

7. 数学原理与物理直觉

在数学上，Embedding 查表操作等价于输入一个 One-Hot 稀疏独热向量与整个权重矩阵相乘： $$[0, 0, 1, 0] \times E = E[2]$$ 但在实际工程实现中，**绝对没有任何框架会真正执行这种极其低效的 One-Hot 稀疏矩阵乘法**，而是直接按地址偏移量（Offset）从连续内存中拷贝整行浮点数据！

8. 打开黑盒：真实工程细节 (内存访问与指针偏移)

C/C++ 底层实现逻辑：
在 llama.cpp 或纯 C 推理引擎中，Embedding 操作就是一条极其纯粹的 memcpy： 
// 内存基地址 + ID * 维度 * sizeof(float)
float* token_vec = &embedding_table[token_id * d_model];
memcpy(output_buffer, token_vec, d_model * sizeof(float));
这是一个纯粹的 Memory-bound 随机内存读取操作。
