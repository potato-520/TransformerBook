1.2 Embedding 嵌入层与语义空间 (Embedding Lookup & Semantic Vectors)

本节核心认知目标：
理解离散整数 Token ID 如何通过查表操作转化为连续高维几何向量，从硬件角度透视 Embedding 的 memcpy 查表本质，掌握词向量空间中余弦相似度与神奇的“向量代数运算”。

1. 📜 科学史话：三幕剧（背景、危机与大师破局）

🎬 第一幕 · 时代背景：One-Hot 独热编码的孤岛世界

在词向量出现之前，计算机表示一个词只能使用 One-Hot 独热编码：
若词表有 50,000 个词，每个词就表示为一个 50,000 维的极长稀疏向量，只有属于自己的那个位置是 1，其余全为 0： $$\text{"apple"} = [1, 0, 0, \dots, 0], \quad \text{"banana"} = [0, 1, 0, \dots, 0], \quad \text{"truck"} = [0, 0, 1, \dots, 0]$$

💥 第二幕 · 遭遇危机：维度灾难与语义正交断层

One-Hot 存在致命的物理缺陷：
1. 显存极其浪费：存放一个句子需要大量的稀疏零阵；
2. 语义完全正交：任意两个词向量的点积均为 0（$\vec{v}_{\text{apple}} \cdot \vec{v}_{\text{banana}} = 0$）。在计算机眼里，“苹果”和“香蕉”的关系，和“苹果”与“重型卡车”的关系没有任何区别！算法无法从语料中迁移任何同义词知识。

💡 第三幕 · 大师破局：2013 年米科洛夫（Mikolov）与 Word2Vec 奇迹

2013 年，Google 青年学者托马什·米科洛夫（Tomas Mikolov）提出了划时代的 Word2Vec！
他践行了语言学大师 J.R. Firth 的名言：“观其伴而知其意（You shall know a word by the company it keeps）”——通过让神经网络根据上下文预测中心词，将 50,000 维的离散稀疏符号压缩投影到 4096 维的连续稠密欧几里得空间中。
当人们把训练好的词向量可视化时，整个学术界被深深震撼了：语义相近的词在空间中紧密聚类，甚至自然涌现出神奇的几何平移代数关系： $$\vec{v}_{\text{King}} - \vec{v}_{\text{Man}} + \vec{v}_{\text{Woman}} \approx \vec{v}_{\text{Queen}}$$ 人类语言的“意义”，第一次在纯粹的几何向量空间中获得了数学实体！

2. Embedding Lookup 的硬件底层真相：指针查表 (RAM Access)

工程师视角去除高深神秘感：
所谓 Embedding 层，其本质就是一块**连续存放的大数组（权重矩阵 $W_E \in \mathbb{R}^{V \times D}$）**！
给定一个 Token ID（例如 $id = 42$），前向传播根本不需要做昂贵的矩阵乘法，它在底层仅仅是一次极速的指针偏移内存拷贝（memcpy）： $$\text{Token Vector} = W_E[42, :] = *(W_E + 42 \times D \times \text{sizeof(float)})$$

4. Python / NumPy 极简 Embedding 查表实现

import numpy as np

class EmbeddingLayer:
    def __init__(self, vocab_size=32000, embed_dim=4096):
        # 权重矩阵表 [V, D]
        self.W_embed = np.random.randn(vocab_size, embed_dim) * 0.02

    def forward(self, token_ids: np.ndarray) -> np.ndarray:
        # 底层直接通过索引切片切出对应行 (零浮点计算)
        return self.W_embed[token_ids]

embed = EmbeddingLayer(vocab_size=10, embed_dim=4)
token_ids = np.array([1, 4, 2]) # 长度为 3 的输入句子
vectors = embed.forward(token_ids)

print("输入 Token IDs:", token_ids)
print("查表输出张量 Shape:", vectors.shape) # [3, 4]
print("第 0 个 Token 向量:", np.round(vectors[0], 3))

5. 打开黑盒：真实工程细节 (Weight Tying 权重绑定)

节省数十亿参数的妙招：
在许多主流模型（如 GPT-2、PaLM、Gemma）中，最开始的 Embedding 权重矩阵 $W_E$ 与模型最后生成 Logits 的 LM Head 输出矩阵 $W_{head}$ 实际上是完全共享同一块显存（Weight Tying）的！
因为输入 Embedding 是“从词到向量”，而 LM Head 是“从向量还原为词”，两者互为转置投影，共享权重既节省了大量显存，又防止了模型过拟合！

6. 动手实验与思考题

思考题：
如果两个词（例如 "good" 和 "great"）在现实语料中经常出现在完全相同的句式上下文中，经过梯度下降训练后，它们的 Embedding 向量夹角会变大还是变小？
提示：会迅速变小，余弦相似度趋向于 1.0！因为反向传播会对相同的上下文预测施加极其相似的梯度更新。
