0.5 梯度下降与反向传播 (Gradient Descent & Backpropagation)

本节目标：从“盲人摸象下山”直觉与控制系统误差反馈出发，理解计算图（Computational Graph）与链式法则（Chain Rule），掌握参数梯度更新的全过程。

1. 它解决什么问题？ (工程师视角黑盒引入)

我们已经有了衡量误差的测量尺（Loss $\mathcal{L}$），但大模型内部有数以亿计的权重参数 $W$。
我们该如何知道“每一个具体的权重参数往哪个方向微调、微调多少，才能让总 Loss 最快下降”？
这就是梯度下降（Gradient Descent）与反向传播（Backpropagation）所要解决的核心工程任务。

2. 梯度的物理直觉：大雾山谷中的盲人

盲人下山隐喻：
想象一个被大雾笼罩的盲人站在高山上的某个位置（当前参数状态），他无法看清山谷最低点在哪（全局最优解）。
但他可以用脚感受脚底四周哪个方向坡度最陡峭（梯度 $\nabla \mathcal{L}$）。沿着最陡峭方向的反方向（负梯度）迈出一步（步长/学习率 $\eta$），就能不断接近山谷底部！

4. 反向传播与计算图链式法则 (极小手算)

极简两节点手算案例：
设前向传播链路为：$z = x \cdot w + b \longrightarrow y = \sigma(z) \longrightarrow \mathcal{L} = (y - y_{true})^2$
已知输入数值：$x = 2.0, w = 1.5, b = 0.5, y_{true} = 5.0$

1. 前向计算：
$z = 2.0 \times 1.5 + 0.5 = 3.5$
设激活函数 $\sigma(z) = z$（恒等映射），则 $y = 3.5$
总误差 $\mathcal{L} = (3.5 - 5.0)^2 = (-1.5)^2 = 2.25$

2. 反向求导（链式回传）：
① 顶层梯度：$\frac{\partial \mathcal{L}}{\partial y} = 2(y - y_{true}) = 2(3.5 - 5.0) = -3.0$
② 传入中间节点：$\frac{\partial \mathcal{L}}{\partial z} = \frac{\partial \mathcal{L}}{\partial y} \cdot \frac{\partial y}{\partial z} = -3.0 \times 1.0 = -3.0$
③ 对权重的梯度：$\frac{\partial \mathcal{L}}{\partial w} = \frac{\partial \mathcal{L}}{\partial z} \cdot \frac{\partial z}{\partial w} = (-3.0) \times x = -3.0 \times 2.0 = -6.0$
④ 对偏置的梯度：$\frac{\partial \mathcal{L}}{\partial b} = \frac{\partial \mathcal{L}}{\partial z} \cdot \frac{\partial z}{\partial b} = (-3.0) \times 1.0 = -3.0$

3. 参数更新（设学习率 $\eta = 0.1$）：
$w_{new} = w - \eta \cdot \frac{\partial \mathcal{L}}{\partial w} = 1.5 - 0.1 \times (-6.0) = 1.5 + 0.6 = 2.1$

5. Python / NumPy 纯手写两层神经网络反向传播

import numpy as np

# 1. 模拟单样本
x = np.array([[1.0, 2.0]])   # Shape: [1, 2]
y_true = np.array([[1.0]])   # Shape: [1, 1]

np.random.seed(42)
W1 = np.random.randn(2, 4)   # 第一层权重 [2, 4]
b1 = np.zeros((1, 4))
W2 = np.random.randn(4, 1)   # 第二层权重 [4, 1]
b2 = np.zeros((1, 1))

lr = 0.05

# 前向传播
z1 = np.dot(x, W1) + b1
a1 = np.maximum(0, z1)
z2 = np.dot(a1, W2) + b2
y_pred = z2

loss = 0.5 * np.sum((y_pred - y_true) ** 2)
print(f"训练前 Loss: {loss:.4f}")

# 反向传播
dL_dz2 = y_pred - y_true
dL_dW2 = np.dot(a1.T, dL_dz2)
dL_db2 = dL_dz2

dL_da1 = np.dot(dL_dz2, W2.T)
dL_dz1 = dL_da1 * (z1 > 0)

dL_dW1 = np.dot(x.T, dL_dz1)
dL_db1 = dL_dz1

# 梯度更新
W1 -= lr * dL_dW1
b1 -= lr * dL_db1
W2 -= lr * dL_dW2
b2 -= lr * dL_db2

new_z1 = np.dot(x, W1) + b1
new_a1 = np.maximum(0, new_z1)
new_pred = np.dot(new_a1, W2) + b2
new_loss = 0.5 * np.sum((new_pred - y_true) ** 2)
print(f"执行一步梯度下降后 Loss: {new_loss:.4f}")

6. 优化器进阶：从 SGD 到现代大模型标配 AdamW

优化器 核心改进思想 物理直觉
SGD 直接按负梯度走固定步长 没有惯性，遇到平坦或鞍点极易卡住
Momentum 引入一阶动量 $v_t = \beta v_{t-1} + (1-\beta)g_t$ 带质量的重球，具有惯性，可冲过局部鞍点
AdamW 一阶动量（方向）+ 二阶动量（自适应步长）+ 解耦权重衰减 现代 LLM（GPT/LLaMA）训练标准

7. 打开黑盒：真实工程细节 (Autograd 与显存开销)

为什么模型训练需要的显存是纯推理的 3~4 倍？
从上述 Python 代码可见：为了在反向传播中计算 dL_dW1 = np.dot(x.T, dL_dz1)，前向传播过程中的全部中间激活值（$x, a_1$ 等）必须一直保存在 GPU 显存中，直到反向传播完成！
这就是为什么在大模型长上下文训练中，需要使用 Activation Checkpointing（激活重计算） 技术——用多算一次前向的时间换取大量的宝贵显存空间。
