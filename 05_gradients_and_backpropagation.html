0.5 梯度下降与反向传播 (Gradients & Backpropagation)

本节核心认知目标：
彻底破除对“反向传播（Backprop）”的高深恐惧，从微积分中最基础的“链式法则（Chain Rule）”出发，理解现代深度学习是如何在复杂的计算图中像流水一样反向传递梯度，并完成参数自适应更新的。

1. 📜 科学史话：三幕剧（背景、危机与大师破局）

🎬 第一幕 · 时代背景：明斯基“多层网络不可训练”的铁幕

在 1969 年明斯基预言“多层感知机无法训练”后，整整 17 年里，所有试图训练深层网络的学者都陷入了泥潭。
当时人们只能用启发式随机搜索：随机微调一下第 1 个参数看 Loss 降不降，再随机调第 2 个参数……
当网络有成千上万个参数时，这种盲盒搜索的计算复杂度呈指数爆炸，比在整个银河系里找一颗特定的沙子还要绝望。

💥 第二幕 · 遭遇危机：微积分求导的“组合爆炸迷宫”

数学家们知道微积分能求导，但如果对每个神经元都单独写出全局偏导数解析式，公式长度会随着层数呈指数级膨胀，根本不可能写成通用代码在计算机上运行。

💡 第三幕 · 大师破局：1986 年辛顿的链式法则与动态规划神技

1986 年，Geoffrey Hinton、David Rumelhart 和 Ronald Williams 在《Nature》上发表了震撼世界的论文，正式将误差反向传播（Backpropagation）推向历史舞台！
他们的核心洞见极其优雅：利用微积分的“链式法则（Chain Rule）”+ 计算机科学的“动态规划（记忆化搜索）”！
无需为每个参数推导全局公式： $$\frac{\partial \mathcal{L}}{\partial W_1} = \frac{\partial \mathcal{L}}{\partial Y} \times \frac{\partial Y}{\partial H} \times \frac{\partial H}{\partial W_1}$$ 只需要从输出端（Loss）开始，从后往前反向遍历一次计算图，前一层的梯度可以直接复用后一层的计算结果！原本需要几天几夜的参数梯度计算，在单次反向遍历中瞬间完成！

2. 梯度下降的物理直觉：高维山谷滚球

物理心智模型：
把损失函数 $\mathcal{L}(W)$ 想象为一片连绵起伏的山谷，参数 $W$ 是山坡上的一颗小球。
梯度 $\nabla \mathcal{L}$ 指向山坡上升最陡峭的方向，因此负梯度 $-\nabla \mathcal{L}$ 就是小球滚落山谷最快的方向！
参数更新公式（步长由学习率 $\eta$ 控制）： $$W_{\text{new}} = W_{\text{old}} - \eta \cdot \frac{\partial \mathcal{L}}{\partial W}$$

4. Python / NumPy 极简两层网络反向传播实现

import numpy as np

np.random.seed(42)
X = np.array([[1.0, 2.0]])   # 输入 [1, 2]
Y_true = np.array([[1.0]])   # 目标 [1, 1]

W1 = np.random.randn(2, 4) * 0.1
W2 = np.random.randn(4, 1) * 0.1
lr = 0.1

# 1. 前向传播 (Forward)
H = np.maximum(0, np.dot(X, W1))     # ReLU 隐藏层 [1, 4]
Y_pred = np.dot(H, W2)                # 输出 [1, 1]
loss = 0.5 * (Y_pred - Y_true) ** 2  # MSE Loss

# 2. 反向传播 (Backward: 链式法则逆向流转)
d_loss = Y_pred - Y_true             # dL/dY
d_W2 = np.dot(H.T, d_loss)           # dL/dW2 = H^T * dL/dY

d_H = np.dot(d_loss, W2.T)           # dL/dH = dL/dY * W2^T
d_Z1 = d_H * (H > 0)                 # ReLU 导数截断
d_W1 = np.dot(X.T, d_Z1)             # dL/dW1 = X^T * dL/dZ1

# 3. 梯度更新 (Step)
W1 -= lr * d_W1
W2 -= lr * d_W2

print("初始 Loss:", round(float(loss), 5))
print("更新后 W1 梯度的模长:", round(float(np.linalg.norm(d_W1)), 4))

5. 打开黑盒：真实工程细节 (AdamW 优化器统治大模型)

为什么大模型一律采用 AdamW 优化器？
朴素 SGD 容易在狭窄的山谷地形中产生剧烈振荡。
AdamW（自适应矩估计 + 解耦权重衰减）通过为每个参数维护一阶动量（历史平均运动方向）和二阶动量（历史方差自适应缩放学习率），实现了对稀疏特征和病态曲面的超强自适应收敛能力！

6. 动手实验与思考题

思考题：
如果在训练过程中，学习率 $\eta$ 设置得过大（例如设为 10.0），小球会发生什么现象？
提示：小球会在山谷两侧剧烈来回弹跳，甚至直接被甩出山谷，造成 Loss 彻底发散（NaN）！这正是现代大模型训练需要精细调度 Learning Rate Warmup & Cosine Decay 的根本原因。
