3.3 LayerNorm 与 RMSNorm (Layer Normalization & RMSNorm)

本节目标：理解为什么深层 Transformer 必须使用归一化层，掌握 LayerNorm 与 BatchNorm 的维度本质区别，以及现代大模型全面采用 RMSNorm 的计算性能收益。

1. 它解决什么问题？ (工程师视角黑盒引入)

在堆叠了几十层（如 LLaMA-3 堆叠了 32~80 层）Block 后，浮点矩阵乘法会产生剧烈的数值膨胀与特征分布漂移（Internal Covariate Shift），导致底层梯度数值爆炸或溢出。
归一化层（Normalization）就像电路系统中的“稳压器/AGC 自动增益控制”，将每个 Token 的特征向量强制拉回均值为 0、方差为 1（或固定均方根）的稳定基准。

2. LayerNorm vs BatchNorm 维度差异

切片维度的根本不同：
  • BatchNorm（图像经典）：跨 Batch 跨序列计算统计量。缺点：依赖 Batch 尺寸，动态序列长度时极难维护。
  • LayerNorm（NLP/Transformer 标准）：在单个样本、单个 Token 自身的全部特征通道 $D$ 上做归一化！ 完全独立于其他 Batch 和其他时序位置。

3. 从 LayerNorm 到更高效的 RMSNorm

标准 LayerNorm 计算公式（包含均值中心化与方差归一化）： $$\text{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta$$ 现代大模型（LLaMA / Mistral / Qwen）发现：均值中心化操作（$x - \mu$）对网络稳定性毫无贡献，真正起作用的是方差缩放！
因此全面升级为去除均值计算、运算速度提升 10%~50% 的 RMSNorm (Root Mean Square Normalization)： $$\text{RMS}(x) = \sqrt{\frac{1}{D} \sum_{i=1}^D x_i^2 + \epsilon}, \quad \text{RMSNorm}(x) = \frac{x}{\text{RMS}(x)} \odot \gamma$$

5. Python / NumPy 极简 RMSNorm 实现

import numpy as np

class RMSNorm:
    def __init__(self, dim: int, eps: float = 1e-6):
        self.eps = eps
        self.gamma = np.ones(dim, dtype=np.float32)

    def forward(self, x: np.ndarray) -> np.ndarray:
        rms = np.sqrt(np.mean(x ** 2, axis=-1, keepdims=True) + self.eps)
        return (x / rms) * self.gamma

x_test = np.array([[10.0, -20.0, 30.0],
                   [1.0,   2.0,   3.0]], dtype=np.float32)

rmsnorm = RMSNorm(dim=3)
out = rmsnorm.forward(x_test)
print("RMSNorm 输出张量:\n", np.round(out, 4))

6. 打开黑盒：真实工程细节 (为什么现代 LLM 全部 Pre-LN？)

Pre-LN vs Post-LN 架构革命：
经典 2017 Transformer 采用 Post-LN（$X_{out} = \text{LN}(X + \text{SubLayer}(X))$），在深层网络中梯度极易在未归一化的残差主线上发散，需要漫长而小心翼翼的 Warmup 预热调参。
现代大模型一律采用 Pre-LN（$X_{out} = X + \text{SubLayer}(\text{RMSNorm}(X))$），让残差主线保持恒等畅通，实现了即插即训的极高数值稳定性！

7. 动手实验与思考题

思考题：
RMSNorm 与 LayerNorm 相比，少算了哪两个量？为什么这能在 GPU 硬件加速上带来显著收益？
提示：少算了“均值 $\mu$”和“偏置 $\beta$”。在 CUDA 核心中，这意味着少做了一次全 Warp 跨线程规约求和（Reduction），显著降低了线程同步与寄存器压力。
