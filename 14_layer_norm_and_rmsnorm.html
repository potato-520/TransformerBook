3.3 LayerNorm 与 RMSNorm (Layer Normalization & RMSNorm)

本节核心认知目标：
理解为什么深层 Transformer 必须使用归一化层，掌握 LayerNorm 与 BatchNorm 的维度本质区别，以及现代大模型全面采用 RMSNorm 的计算性能收益。

1. 📜 科学史话：三幕剧（背景、危机与大师破局）

🎬 第一幕 · 时代背景：2016 年 Jimmy Ba 与 Hinton 的 LayerNorm

在堆叠了数十层的大网络中，浮点矩阵乘法会导致特征数值不断膨胀漂移（Covariate Shift）。
2016 年，Jimmy Ba 与 Geoffrey Hinton 提出了 LayerNorm（层归一化）：在单个 Token 的特征维度上强制将均值拉到 0、方差拉到 1，极大稳定了深层网络的训练。

💥 第二幕 · 遭遇危机：均值计算带来的 GPU 全局规约同步瓶颈

然而，标准 LayerNorm 包含均值中心化（$x - \mu$）与方差归一化两步规约操作。
在现代大模型几十层的连续调用中，计算均值需要触发 GPU Warp 级别的跨线程同步求和（All-Reduce），频繁打断计算流水线，成为不可忽视的访存瓶颈。

💡 第三幕 · 大师破局：2019 年张彪与森里奇的 RMSNorm 极简革命

2019 年，中国学者张彪（Biao Zhang）与爱丁堡大学的 Rico Sennrich 做了一项极具颠覆性的实验：
他们发现：均值中心化操作（$x - \mu$）对模型的训练稳定性没有任何贡献，真正起稳压作用的仅仅是方差缩放！
于是他们大胆砍掉了均值计算，发明了 RMSNorm（Root Mean Square Normalization）： $$\text{RMS}(x) = \sqrt{\frac{1}{D} \sum_{i=1}^D x_i^2 + \epsilon}, \quad \text{RMSNorm}(x) = \frac{x}{\text{RMS}(x)} \odot \gamma$$ 这一极简改进直接减少了 50% 的跨线程同步，算子速度提升 10%~50%，被 LLaMA-1/2/3、Mistral、Qwen 全面采用为现代大模型的标配！

3. Python / NumPy 极简 RMSNorm 实现

import numpy as np

class RMSNorm:
    def __init__(self, dim: int, eps: float = 1e-6):
        self.eps = eps
        self.gamma = np.ones(dim, dtype=np.float32)

    def forward(self, x: np.ndarray) -> np.ndarray:
        rms = np.sqrt(np.mean(x ** 2, axis=-1, keepdims=True) + self.eps)
        return (x / rms) * self.gamma

x_test = np.array([[10.0, -20.0, 30.0]])
rmsnorm = RMSNorm(dim=3)
print("RMSNorm 输出:\n", np.round(rmsnorm.forward(x_test), 4))

4. 打开黑盒：真实工程细节 (为什么现代 LLM 全部 Pre-LN？)

Pre-LN 架构革命：
经典 2017 Transformer 采用 Post-LN（$X_{out} = \text{LN}(X + \text{SubLayer}(X))$），梯度容易在残差主线上发散。
现代大模型一律采用 Pre-LN（$X_{out} = X + \text{SubLayer}(\text{RMSNorm}(X))$），让残差主线保持恒等畅通，实现了即插即训的极高数值稳定性！

思考题：
RMSNorm 与 LayerNorm 相比，少算了哪两个量？为什么这能在 GPU 硬件加速上带来显著收益？
提示：少算了“均值 $\mu$”和“偏置 $\beta$”。少做了一次全 Warp 跨线程规约求和，降低了线程同步延迟与寄存器开销。
