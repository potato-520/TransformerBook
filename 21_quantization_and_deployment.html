4.5 模型量化与边缘部署 (Quantization & Edge Deployment)

本节目标：从嵌入式定点数（Fixed-point）与 DSP 算力优化视角，掌握 FP32 $\to$ FP16 $\to$ INT8 / INT4 模型量化的数学映射公式，理解 Weight-Only 量化与 MCU/NPU 边缘端硬件加速。

1. 它解决什么问题？ (工程师视角黑盒引入)

一个标准的 70B 参数大模型以 FP16（16 位浮点，每参数 2 字节）存储时，仅权重就需要 $70 \times 2 = 140\text{ GB}$ 显存，至少需要 2 张昂贵的 A100/H100 80GB 专业计算卡。
但在很多工业边缘端（车载 MCU、嵌入式 Linux 板卡、高通 NPU 手机芯片）上，内存往往只有 8GB~16GB。
模型量化（Quantization）：通过定点映射，将每个 16 位浮点数压缩为 8 位或 4 位整数（INT8 / INT4），直接将显存需求缩减为原来的 $\frac{1}{2} \sim \frac{1}{4}$，并极大提升定点 MAC 计算吞吐！

2. 定点量化与反量化核心数学映射

对称定点量化（Symmetric Quantization）公式：
1. 量化 Scale 比例因子： $$S = \frac{\max(|X|)}{q_{max}} \quad (\text{INT8 时 } q_{max}=127)$$ 2. 浮点 $\to$ 定点量化： $$Q = \text{clip}\left( \text{round}\left(\frac{X}{S}\right), -q_{max}, q_{max} \right) \in \text{INT8}$$ 3. 定点 $\to$ 浮点反量化（Dequantization）： $$\hat{X} = Q \times S \approx X$$

4. Python / NumPy 极简 INT8 量化与反量化实现

import numpy as np

def quantize_int8(tensor: np.ndarray):
    max_val = np.max(np.abs(tensor))
    scale = max_val / 127.0
    
    q_tensor = np.clip(np.round(tensor / scale), -127, 127).astype(np.int8)
    return q_tensor, float(scale)

def dequantize_int8(q_tensor: np.ndarray, scale: float) -> np.ndarray:
    return q_tensor.astype(np.float32) * scale

weights_fp32 = np.random.randn(4, 4).astype(np.float32)
q_weights, scale = quantize_int8(weights_fp32)
recovered_weights = dequantize_int8(q_weights, scale)

print("原始 FP32 权重 (第一行):\n", weights_fp32[0])
print("量化 INT8 权重 (第一行):\n", q_weights[0])
print("反量化还原权重 (第一行):\n", np.round(recovered_weights[0], 4))

5. 打开黑盒：真实工程细节 (AWQ / GPTQ 与边缘 NPU)

为什么 INT4 精度几乎不掉点（AWQ 核心思想）？
研究发现，神经网络中只有约 1% 的关键权重（Salient Weights / Outliers） 对输出质量起决定性作用。
现代工业级量化算法（AWQ / GPTQ）通过保护这 1% 的关键权重不被剧烈舍入，将其余 99% 的普通权重激进压缩到 INT4，实现了在 70B 模型上“体积缩小 4 倍而准确率近乎零损失”的工程奇迹！
